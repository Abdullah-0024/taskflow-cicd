About TaskFlow

TaskFlow is a lightweight, browser-based task management app built for DevOps practice. It demonstrates a full CI/CD pipeline using GitHub Actions, Docker, and Render.

How to Use

  • Go to Home to see task summary counts.
  • ClickAdd Task to create a new task.
  • Use Task List to view and filter all tasks.
  • Click any task to view its Task Detail.
